# Decorators

Decorators are utility classes that apply a stylized look and feel without requiring structural markup like a component. Apply them directly to existing elements using a single class name.

## Naming

Decorator classes follow the pattern `fmxe-deco-[descriptor]`, where `deco-` identifies the class as a decorator and `descriptor` names the specific style applied.

```html
<h2 class="fmxe-deco-heading-border">Why FMX</h2>
```

## Available decorators

| Class | Description |
|---|---|
| [`fmxe-deco-heading-border`][heading-border] | Adds a short accent bar above text |
| [`fmxe-deco-wave-container`][wave-container] | Applies a wavy bottom edge to a section that flows into the next |
