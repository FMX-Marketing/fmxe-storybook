# Layout

Layout is a major set of frames on which we can hang content and design
elements.

Our layout system provides a toolkit for positioning within a grid
layout, spacing, and grouping of elements like cards. This all can be configured
flexibly with optional mobile-first responsive breakpoints.

## Responsive breakpoints

Based on Bootstrap, Electric references five responsive breakpoints. The five
tiers are as follows:

1. Extra small (`xs`)
2. Small (`sm`)
3. Medium (`md`)
4. Large (`lg`)
5. Extra large (`xl`)

As noted above, each of these breakpoints have their own container, unique class
prefix, and modifiers. Here are the thresholds and class prefixes for the
breakpoints:

## Grid system

Most FMX website layouts use the [grid system][2]. It provides a set of
utilities for composing row- and column-based layouts scaling from mobile up
through desktop viewport sizes.

## Spacing

Electric [spacing utilities and tokens][1] provide a toolkit for consistent
spacing of elements vertically and horizontally.

Utilities for padding and margin can be applied as square and squish insets,
