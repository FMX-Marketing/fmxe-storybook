# FMXE Tokens

Design tokens are the raw custom values utilized within our [Figma designs](https://www.figma.com/design/bg8ecYNq9ja8DbKW07QLrB/FMX-Styles?node-id=1211-18&p=f&vars=1&var-id=4379-23451&m=dev). These values serve as the core configuration for our web development projects at FMX.

## Design Tokens in Projects

Due to the nature of the projects we work on, it's important that our CSS and design system is flexible.

**General Project Rules:**

1. The design tokens are the raw original values defined as CSS and should be a direct match to Figma variables.
2. Additional tools such as SCSS only need to reference the original variables and can utilize shortened name variations.
3. On projects that do not have addiotonal tools for styling default to CSS variables.
4. If a project utilizes typography and styles outside of the project, we do not need to include these in the design system only the project.

## Using Modes

Some design tokens utilize a "mode" which identifies the device size of that design token corresponds with. Generally, modes are limited to font-size and line-height. As such, we should strive to use the correct mode for the right device size.

_Note: If you encounter a mode that is incorrect for the Figma design, please leave a comment in Figma and use the correct mode._

## Version Control

As our tokens go through updates, it's important to version control these specific items. Versions use the major, minor, patch system that is represented as a three digit number `1.2.3`.

- Major: This represents a large overhaul or breaking change.
- Minor: This represents a new feature or addition.
- Path: This represents a fix or revision.
