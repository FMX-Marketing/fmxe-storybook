# Shapes and Elevation

Effects of shapes and elevation in FMX's digital brand manifest themselves in
two areas:

1. Border radius
2. Shadows

## 1. Shapes: border radius

There are currently two t-shirt sizes and a round style of border radius for use
on cards, buttons, images, and other types of panels.

### 1.2 Small

Use on small components and containers, but use sparingly on larger objects.

Small border radius can be applied via the `--fmxe-border-radius-sm` token.

```html
<style type="text/css">
    .box {
        background-color: #fff;
        border-radius: var(--fmxe-border-radius-sm);
    }
</style>

<section class="bg-color-gray-light p-lg">
    <div class="box p-lg">
    </div>
</section>
```

### 1.3 Medium

Commonly used for cards and other medium- to large-style components and
sections.

Large border radius can be applied via the `--fmxe-border-radius-lg` token.

```html
<style type="text/css">
    .box {
        background-color: #fff;
        border-radius: var(--fmxe-border-radius-md);
    }
</style>

<section class="bg-color-gray-light p-lg">
    <div class="box p-lg">
    </div>
</section>
```

### 1.4 Round

Can be used for more exaggerated roundness on objects such as buttons. When
applied to square objects, it will appear as a circle.

Small border radius can be applied via the `--fmxe-border-radius-round` token.

```html
<style type="text/css">
    .circle {
        border-radius: var(--fmxe-border-radius-round);
        height: 100px;
        width: 100px;
    }
</style>

<section class="bg-color-gray-light p-lg">
    <div class="circle">
    </div>
</section>
```

### 2.2 Shadows

Shadows come in two t-shirt sizes: small and medium.

By default, shadows mimic nature with a dark gray shadow color. This can be
applied via the `--fmxe-shadow-color` and `--fmxe-shadow-*` tokens (where
`*` is the size `sm` or `md`).

```html
<style type="text/css">
    .small-box {
        box-shadow: 0 0 var(--fmxe-shadow-sm) var(--fmxe-shadow-color);
    }

    .medium-box {
        box-shadow: 0 0 var(--fmxe-shadow-md) var(--fmxe-shadow-color);
    }
</style>

<section class="bg-color-gray-light p-lg">
    <figure class="small-box p-lg bg-color-white">
    </figure>

    <figure class="medium-box p-lg bg-color-white">
    </figure>
</section>
```

### 2.3 Glow effect

Shadows can also be transformed into a glow effect by changing the shadow color
to electric blue. This is typically applied on hover/active/focus states.

This can be accomplished with the `--fmxe-shadow-color-glow` token.

```html
<style type="text/css">
    .shadowed {
        --shadowed-color: var(--fmxe-shadow-color);
        box-shadow: 0 0 var(--fmxe-shadow-sm) var(--shadowed-color);
    }

    .shadowed:hover,
    .shadowed:active,
    .shadowed:focus {
        /* See https://stackoverflow.com/a/3012987 */
        --shadowed-color: var(--fmxe-shadow-color-glow);
    }
</style>

<section class="bg-color-gray-light p-lg">
    <figure class="shadowed p-lg bg-color-white">
    </figure>
</section>
```
