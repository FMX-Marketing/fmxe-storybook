# Layout

Layout is a major set of frames on which we can hang content and design
elements.

Our layout system provides a toolkit for positioning within a grid
layout, spacing, and grouping of elements like cards. This all can be configured
flexibly with optional mobile-first responsive breakpoints.

## Responsive breakpoints

Based on Bootstrap, Electric references five responsive breakpoints. The five
tiers are as follows:

1. Extra small (`xs`)
2. Small (`sm`)
3. Medium (`md`)
4. Large (`lg`)
5. Extra large (`xl`)

As noted above, each of these breakpoints have their own container, unique class
prefix, and modifiers. Here are the thresholds and class prefixes for the
breakpoints:

|                       | xs   | sm       | md       | lg       | xl        |
|-----------------------|------|----------|----------|----------|-----------|
| Screen min width      | 0    | ≥576px   | ≥768px   | ≥992px   | ≥1200px   |
| Class prefix          |      | `sm:`    | `md:`    | `lg:`    | `xl:`     |

Responsive class prefixes can be applied across several different layout
utilities:
* [Grid][2]
* [Spacing][1]

## Grid system

Most FMX website layouts use the [grid system][2]. It provides a set of
utilities for composing row- and column-based layouts scaling from mobile up
through desktop viewport sizes.

```html
<main class="container">
    <div class="row">
        <figure class="col-12 md:order-last lg:col-3 mb-md md:mb-md">
            <img src="https://placekitten.com/600/600" alt="kitten">
        </figure>

        <div class="col-12 md:col-6 lg:col-9">
            <h1>This is a page title</h1>
            <p>Welcome to our grid-based page.</p>
        </div>
    </div>
</main>
```

See the chapter about the [grid][2] for more information.

## Spacing

Electric [spacing utilities and tokens][1] provide a toolkit for consistent
spacing of elements vertically and horizontally.

Utilities for padding and margin can be applied as square and squish insets,
stacked, inline, and on the grid.

Following is an example of applying a medium inset padding to a frame and a
small stack margin to the bottom of the first element.

```html
<style type="text/css">
    .frame {
        background: red;
        padding: var(--fmxe-space-inset-md);
    }

    .frame:first-child {
        margin-bottom: var(--fmxe-space-stack-sm);
    }

    .inner {
        background: white;
        padding: var(--fmxe-space-inset-lg);
    }
</style>

<main>
    <figure class="frame">
        <div class="inner">
            space-inset-lg
        </div>
    </figure>

    <figure class="frame">
        <div class="inner">
            space-inset-lg
        </div>
    </figure>
</main>
```

See the chapter about the [spacing][1] for more information.

## Cards

*Note: Card components and their documentation are currently being updated.*

A card component can contain a header, image, body, and footer.

```html
<div class="card" style="width: 18rem;">
  <img src="https://placekitten.com/800/500" class="card-img" alt="kitten">

  <div class="card-body">
    <h3 class="card-title">
        Card title
    </h3>
    <p>
        Some quick example text to build on the card title and make up the bulk
        of the card's content.
    </p>
  </div>
</div>
```

All card components in the design system extend this base card component and
override properties within to add extra visual effects.

### Card decks

Cards are typically laid out within a card deck grid, which sets the number of
cards per row based on what makes sense for each breakpoint.

A base card deck looks like the following:

```html
<div class="card-deck">
    <div class="card">
        <div class="card-body">
            <h3 class="card-title">
                I'm a card
            </h3>
        </div>
    </div>

    <div class="card">
        <div class="card-body">
            <h3 class="card-title">
                I'm a card
            </h3>
        </div>
    </div>

    <div class="card">
        <div class="card-body">
            <h3 class="card-title">
                I'm a card
            </h3>
        </div>
    </div>

    <div class="card">
        <div class="card-body">
            <h3 class="card-title">
                I'm a card

        </div>
    </div>
</div>
```
