# FMX Electric Storybook

A lightning-fast front-end system designed to power beautiful, accessible web experiences across the FMX organization.

## About

FMX Electric (FMXE) is a design system and component library built with Storybook. It provides reusable components, design tokens, and styling guidelines for FMX web projects.

## Getting Started

### Installation

```bash
npm install
```

### Development

Run Storybook in development mode:

```bash
npm run storybook
```

This will start Storybook at `http://localhost:6006`

### Build

Build a static version of Storybook:

```bash
npm run build-storybook
```
